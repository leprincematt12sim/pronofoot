📜 Règles du Jeu

🎮 Comment jouer ?

PronoFoot est une compétition de pronostics entre amis. Chaque semaine, pronostiquez les scores des matchs des 5 grands championnats européens et de la Ligue des Champions.

📝 Faire un pronostic

  • Allez dans l'onglet ⚽ Matchs
  • Entrez le score que vous prédisez pour chaque match (ex: 2-1)
  • Cliquez sur 💾 Sauvegarder
  • Vous pouvez modifier vos pronostics tant que le match n'a pas commencé

⭐ Système de points

🎯 Score exact = 5 points
Vous trouvez le score exact du match (ex: vous dites 2-1, le match finit 2-1)
✅ Bon résultat = 3 points
Vous trouvez le bon vainqueur ou le match nul, mais pas le score exact (ex: vous dites 3-0, le match finit 2-1 → vous aviez raison que l'équipe à domicile gagne)
❌ Mauvais résultat = 0 point
Vous n'avez pas trouvé le bon vainqueur

🎯 Bonus de saison

  • 🏆 Vainqueur Ligue des Champions : +75 points
  • 🥇 Champion national (PL, Liga, Serie A, BuLi, L1) : +50 points chacun

🏆 Classement

Le classement se met à jour automatiquement dès que l'administrateur entre les scores des matchs. Vous pouvez voir votre position en temps réel dans l'onglet Classement.

🔒 Politique de Confidentialité & CGU

1. Informations collectées

Lors de votre inscription, nous collectons uniquement :

  • Votre pseudo (choisi par vous)
  • Votre adresse email
  • Vos pronostics et points

2. Stockage des données

Toutes vos données sont stockées localement dans votre navigateur (localStorage). Aucune donnée n'est envoyée à un serveur tiers. Si vous videz les données de votre navigateur, vos pronostics seront perdus.

3. Partage des données

Nous ne partageons aucune donnée avec des tiers. Vos informations ne sont visibles que par les autres joueurs de la compétition (pseudo et points uniquement).

4. Vos droits

  • Vous pouvez supprimer votre compte à tout moment en contactant l'administrateur
  • Vous pouvez modifier votre pseudo en vous réinscrivant
  • Vous pouvez vider vos données en effaçant le cache de votre navigateur

5. Conditions d'utilisation

  • Ce site est destiné à un usage récréatif et amical
  • Aucun gain financier n'est associé aux pronostics
  • L'administrateur se réserve le droit de modifier les scores en cas d'erreur
  • Les résultats officiels des matchs font foi

6. Contact

Pour toute question, contactez l'administrateur du groupe via l'email utilisé lors de l'inscription.
